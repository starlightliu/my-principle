# 我的原则（My Principles）

个人原则可视化页面，将 36 条判断、行动、关系、学习与投资仓位原则组织成一张可交互查阅的决策地图。

## 页面结构

- **决策全景**：5 层个人决策操作系统架构图与 KPI 概览。
- **判断与回路**：4 步决策复核播放器、刘润的回路、指数 vs 对数增长对比与 SCAMPER 七问速查。
- **关系与行动**：分歧、相处、带人、受挫四大高频场景的动作切换。
- **仓位红线**：交互式单品 20% / 同类 30% 上限与「买卖同源」检验器。
- **原则速查**：按 5 个主题与 15 个场景标签实时检索全部 36 条原则及标签释义。

## 文件说明

- `index.src.html`：Visual Explainer 源文件
- `index.html`：由 Visual Explainer kit 渲染生成的自包含静态页面（GitHub Pages 入口）
